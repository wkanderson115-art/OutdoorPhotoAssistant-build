# V12 本地专业精修：四项关键攻坚报告

本次在 V11 源码基础上修改。**源码解析通过不代表 Xcode 编译或真机验收通过。**

## 1. 人像局部瑕疵修复
新增 `RetouchPipeline.healSpotFromCleanSkin`：用户指定瑕疵点和邻近健康皮肤采样点，使用纹理克隆、软边缘合成，保留真实皮肤纹理。保留原有手动中值修复。**尚未实现可靠的全自动痘痘/痘印识别**，需要标注样本与 Core ML 模型。

## 2. 宠物与自然物体前景分割
新增 iOS 17+ `VNGenerateForegroundInstanceMaskRequest` 前景实例蒙版，针对宠物和微距场景保护前景细节、背景轻降噪；失败回退到已有图像。**该 API 是通用前景分割，不是专用毛发分割；也不提供天空/植被语义标签。**

## 3. 高分辨率性能
新增 `visionProxy`：将 Vision 输入长边限制在 1600 像素，原始 Core Image 图像仍按完整尺寸处理，减少 Vision 识别解码成本。未实现完整分块渲染、内存压力自适应和 48MP 真机性能验收。

## 4. 商业质量审核
在 `RetouchPipeline.assess` 接入 `RetouchPixelAudit` 的明暗裁切、大面积变化与色差指标。已有 `CommercialQualityGate` JPEG sRGB 技术检查与人工复核机制。**无法替代专业肤质、毛发、身份与生成伪影审核**。

## 验证情况
- ZIP 文件可完整解压并校验 CRC。
- 全部 Swift 源文件在当前 Linux Swift 工具链执行 `swiftc -frontend -parse` 语法解析通过。
- 当前环境没有 Xcode/iOS SDK，未完成 iOS 类型检查、链接、模拟器及真机编译。
- 未执行 12MP/24MP/48MP 真机耗时、峰值内存与画质盲测；不能宣称四项已达到商业正式版标准。

## Mac 最终验收
```bash
xcodebuild -list -project OutdoorPhotoAssistant.xcodeproj
xcodebuild -project OutdoorPhotoAssistant.xcodeproj -scheme OutdoorPhotoAssistant -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```
并对人像、宠物、风景、商品各不少于 20 张原始照片测试，人工检查细节、色彩、边缘与失败回退，另测试 12/24/48MP 内存峰值与耗时。
