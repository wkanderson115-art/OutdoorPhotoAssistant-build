# V7 关键缺口攻坚（源码升级，未编译）

## 本轮新增
- 本地精修加入手动点选小瑕疵的局部中值修复，羽化范围随图像尺寸缩放；每次修复保存为独立历史版本，便于回退和人工比较。此算法适合小面积瑕疵，不适合发丝、轮廓或大面积重建。
- 人像类本地管线加入 Vision 面部关键点检测与低强度局部降噪蒙版；眼、眉、鼻、嘴区域排除处理。未检测到可信人脸时保留原处理路径。此功能不宣称祛痘或毛发修复。
- 将先前新增的 `RetouchRecovery.swift`、`RetouchPixelAudit.swift`、`RetouchSpecialist.swift` 登记进 Xcode Sources。
- 付费 AI 调用在请求前为任务创建独占占位文件；恢复任务后读取该状态，阻止同一任务因重启而再次发起请求。网络失败后仍需新建任务才能再次尝试。
- `RetouchPixelAudit.swift`：96×96 抽样分析平均像素变化、较大变化覆盖率、极端黑白裁切比例。用于发现明显过度处理，不代表 AI 伪影、身份一致性已通过验证。
- `CommercialQuality.swift`：接入像素抽样诊断，保留商业人工审核要求。
- `CommercialRetouchView.swift`：历史版本可点选预览、作为分享版本，不覆盖原图及任何旧文件；恢复任务后亦可切换版本。

## 仍未完成且不可宣称完成
- 专业祛痘、皮肤保护、毛发修复模型的集成与真实样张验收。
- Seedream 非刚性图像配准、语义区域蒙版及可靠结构保护。当前保守融合拒绝不安全结果。
- 人脸身份一致性与 AI 伪影模型，商业自动放行不可用。
- 完整断点续跑、后台任务状态机与服务端 API 幂等保证。客户端仅阻止同一任务重复发起请求。
- Xcode 编译、iPhone 真机运行、真实 API 联调。

## 验收建议
1. 在 macOS 的 Xcode 中打开工程，执行 Clean Build Folder 和真机构建。
2. 对同一照片运行多次，确认原图 SHA 不变、版本文件名互不覆盖、历史预览能切换。
3. 用过曝、全黑、严重 AI 改写照片验证质量警告。
4. 用不同尺寸 AI 输出验证融合拒绝且保留本地版。
5. API 失败时检查单次付费调用限制和恢复行为。
