# V6 专用处理与恢复升级说明

本次新增：按摄影类别配置降噪与锐化、色温和高光阴影处理、EXIF方向归一、SHA256版本清单、原图及历史任务恢复入口、版本文件校验。原始数据以字节形式保存，不覆盖。

## 尚未完成且不得声称完成
- 真正的祛痘、痘印、毛发修复、商品级材质保护等需要训练/集成经过许可的 Core ML 专用模型及测试集。现阶段是按类别参数处理，并非完整80套独立算法。
- Seedream 几何配准仍仅支持原尺寸低差异保守融合；大幅生成性修改拒绝融合。
- 人物身份一致性、AI伪影识别和商业授权核查未达到自动签发标准；必须人工复核。
- 当前运行环境没有 Xcode/Apple iOS SDK，不能完成 iOS 编译与真机验收。项目包含 GitHub Actions macOS 构建工作流；上传到仓库后才能执行。
- API Key 请通过 App 设置配置，不要放进源代码。
