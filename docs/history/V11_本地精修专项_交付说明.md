# V11 本地精修专项：人物分割与背景独立降噪

## 已实现
- 使用 Apple Vision 的 `VNGeneratePersonSegmentationRequest` 提取人物前景掩码（iOS 17.6 目标）。
- 使用 Core Image 将低分辨率人物掩码映射到照片像素尺寸，并对掩码边缘羽化。
- 在人像类别中，背景执行轻量降噪，人物沿用原有精修路径，降低对衣物、头发和肤质的误处理。
- Vision 分割失败时返回原图像处理结果，不让分割失败中断整个流程。
- 保留既有 20 类 80 预设、版本管理与独立引擎入口。

## 验证
- Linux Swift 前端 `-parse` 检查工程全部 Swift 源码：通过（仅语法检查）。
- 未进行 Apple SDK 类型检查、Xcode 编译、iPhone 真机测试或真实成片 A/B 测试。

## Xcode 验证建议
1. 在 Mac 打开 `OutdoorPhotoAssistant.xcodeproj`，选择 iOS 模拟器构建。
2. 以室内逆光人像、复杂头发背景、多人合影和无人物照片测试蒙版边界。
3. 在 12MP/24MP/48MP 输入下测试峰值内存、运行耗时与输出尺寸。
4. 核对人像边缘是否有灰边、光晕或降噪不连续。
