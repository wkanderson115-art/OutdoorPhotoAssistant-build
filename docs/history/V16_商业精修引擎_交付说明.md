# V16 商业精修引擎 · 交付说明

## 0. 一句话结论

「人工精修」这一块从**全局滤镜式自动增强**重写为**分层、蒙版驱动、频率感知的专业修图链路**：祛瑕疵（样本块修补）→ 高低频磨皮（保留毛孔）→ 中频明暗重塑（中性灰 D&B）→ 五官（眼/眼下/牙/唇）→ 影调 → 3D LUT 调色（肤色保护）→ 输出锐化，全链路配一套量化质检门（纹理保留率 / 肤色 ΔE00 / 接缝 / 裁切 / SSIM）并带回退修复。

参考实现已在本机跑通并在真实样张上通过质检，实测见第 4 节；Swift 端同参数、同门限移植，真机编译需在 macOS 上执行（第 6 节给了确切命令）。

---

## 1. 诊断：V15 的「本地精修」为什么达不到商业标准

| 问题 | 证据（V15 源码） |
| --- | --- |
| 80 个预设参数完全相同 | `PresetCatalog.swift` 里 p01–p80 的 exposure/contrast/saturation/warmth 全是一组常数 |
| 链路里没有「修图」 | `RetouchPipeline.process` 只做 exposureAdjust → highlightShadowAdjust → colorControls → temperatureAndTint → noiseReduction → sharpenLuminance |
| 没有皮肤概念 | 全图降噪 + 全图锐化，没有皮肤蒙版、没有高频/低频分离 |
| 没有瑕疵处理 | 只有手动点选 + median 替换，`healSpot` 就是中值模糊，没有样本块搜索、没有梯度域融合 |
| 没有五官处理 | 无眼白/虹膜/眼下/牙/唇 |
| 质检不会给出结论 | `assess()` 永远 `acceptable: false`，只有 5 个像素指标（96×96 缩略图上算的） |
| 方向归一化补丁 | 只在 pipeline 里做了一次 EXIF 归一化，质量审核按显示尺寸比较 |

结论：V15 是「保守自动增强」，不是精修。V16 把它换成了真正的 retouch 链路。

## 2. 新链路（9 个阶段）

顺序与 `tools/retouch_lab/portrait.py` 一一对应，Swift 端 `RetouchPipeline.process` 同序。

| # | 阶段 | 做什么 | 关键参数（6000 px 长边基准，按 `r' = r × longEdge/6000` 缩放） |
| --- | --- | --- | --- |
| 1 | 分析 | Vision 人脸 + 五官关键点 → 归一化几何；皮肤概率图（YCbCr 门限 + Lab 色距 + 引导滤波细化 + 去发丝/眉/眼/唇）；噪声 σ；白平衡（低饱和 30% 灰世界，±7% 限幅）；皮肤中位色 | 引导滤波 r = 0.04×脸宽，eps 2e-3；羽化 0.8 px/千像素 |
| 2 | 瑕疵检测 | 尺度归一化 LoG（σ = 0.004 / 0.006 / 0.009 × 脸宽），每尺度按自身 MAD 归一化后取最大；色偏 ΔE00 门控；环形方差、圆度、梯度、高光/深影排除；NMS；半径由胜出尺度给出 | 阈值 z > 3.4+3.2(1−sens)；每图上限 80 点 |
| 3 | 祛瑕疵 | 在 1.4–4× 半径环带内按「模糊 Lab SSD + 均值色差」选源块；只搬梯度（低频校正场），羽化 alpha 合成；顽固点自动放大补丁二次修补 | patch R = 1.7r；α 半径衰减 ^1.3；二次 pass 半径 +1 |
| 4 | 高低频磨皮 | `low = G(r)`，`out = mix(img, low, k)`，k = smooth×0.55、纹理保留 = 1−k×(1−g) 的等效实现：高频带保留 82%；再用 **color blend** 做纯色度均匀（亮度取原图，毛孔完全不动） | 平滑 r 5 px，amount 0.55，textureGain 0.82；色度半径 16 px，amount 0.5 |
| 5 | 明暗重塑 D&B | 24 px 低通作为「理想光照」，只作用皮肤，**luminosity blend** 合成（色度零漂移），|ΔL*| 单次 ≤4 | amount 0.30，clip 4.0 L* |
| 6 | 五官 | 眼白提亮+去血丝降饱和、虹膜局部对比、瞳孔压暗；眼下（仅暗部）提亮 luma +3.4；牙去黄降饱和、唇饱和 +16%；全部径向羽化蒙版 | eye 0.55 / underEye 0.45 / teeth 0.55 / lip 0.20（0–1 强度） |
| 7 | 影调 | 白平衡 → 曝光（肤色中位对齐 target，限 ±0.9 EV）→ 高光肩部 rolloff 0.86 → 阴影 lift 0.10 → S 曲线 contrast 1.04 → vibrance 0.05 | 见 `RetouchParameters` |
| 8 | 调色 | 33³ CIColorCube（red-fastest，RGBA float32），lift/gamma/gain + 阴影/高光染色，按 look 生成，strength 混回原图；皮肤 ΔE 上限 3.0 保护 | lutStrength 0.40；`RetouchLUT.cubeData` |
| 9 | 输出 | clarity（非皮肤区局部对比）、输出锐化（小半径、阈值、避开皮肤）、暗角、可选胶片颗粒；高光天花板 0.985 + 黑位地板 0.012（杜绝「修出来的裁切」） | sharpen r 0.8 px，amount 0.18，threshold 0.008 |

**为什么这样才叫商业级**：所有编辑都是「分解 → 只在目标频带施加增益 → 空间蒙版限制 → 限幅防越界」。磨皮只压低频、色度只换 chroma、D&B 只改 luma、调色带肤色保护，因此毛孔、发丝、唇线、眼神光都不会被抹掉——这正是专业修图与业余滤镜的分水岭。

## 3. 质检门（Commercial QC Gate）

`RetouchQualityGate`（Swift）/ `quality_gate`（参考实现）输出固定 10 个指标，并在失败时返回可执行的回退策略：

| 指标 | 门限 | 含义 |
| --- | --- | --- |
| `texture_retention` | 0.50 – 1.15（人像） | 皮肤区 0.6–4 px 带通能量比；<0.5 塑料、>1.15 锐化过度 |
| `skin_tone_de` | ≤ 3.0 | 皮肤中位色 CIEDE2000（已做色调对齐，曝光/白平衡修正不算色差） |
| `skin_luma_shift` | ≤ 18 | 皮肤 L* 平均偏移 |
| `clipping_skin` | ≤ 0.002 | **新增**皮肤裁切占比 |
| `clipping_full` | ≤ 0.01 | **新增**全图裁切占比（原图已裁切的不计入） |
| `seam_ratio` | \|x−1\| ≤ 0.30 | 蒙版边界梯度比（中位数），检测磨皮/修补接缝 |
| `ssim` | ≥ 0.85 | 结构相似度 |
| `blemish_clearance` | ≥ 0.6（检测到 ≥3 处时才判定） | 修补前后的瑕疵对比度清除率 |
| `spots_before` | 信息 | 检出瑕疵数 |

失败自动回退：纹理过低 → 降 smoothAmount 并加 textureGain；裁切 → 降曝光目标与高光拐点；接缝 → 降 D&B 与平滑强度，然后重跑（最多 2 次）。

## 7. 已知边界

1. **不是学习模型**：瑕疵检测是 LoG 尺度空间 + 色偏门控，召回不如训练过的分割网络；雀斑、痣、胡茬会被部分保留（这是刻意的——商业精修默认不抹雀斑）。预设里 `blemishSensitivity` 可调。
2. **发丝级分割**：皮肤蒙版用 YCbCr+Lab+引导滤波+亮度门限去发丝，遇到大面积刘海仍可能把极暗发丝边缘算进皮肤；Swift 端可直接换成 Vision 前景/人物蒙版做先验（接口已留）。
3. **48 MP 内存**：Swift 端所有 CPU 分析都在 ≤2000 px 代理上，全分辨率只走 GPU 图；最终仍需一张完整位图（`LocalTiledRenderer` 分块渲染），峰值内存要真机 Instruments 验证。
4. **场景分支**：白平衡/去雾/影调/锐化 + 场景质检（无肤色项），不做天空替换、不做局部重光。
5. **色彩管理**：导出为 sRGB JPEG（q0.95，方向重置为 1），未写 XMP/ICC 自定义配置；原图字节另存不覆盖。

## 8. 下一步（按性价比排序）

1. 用 Vision 人物/前景蒙版替换自研皮肤门控，发丝边界会更稳（半天工作量）。
2. 接入 Core ML 瑕疵分割（Retouch4me 路线），把 `BlemishScanner` 换成模型输出，其余链路不变。
3. 3D LUT 提升到 65³ + 四面体插值，供印刷交付。
4. 批量队列（同一预设批量出片 + 质检汇总表），这是商业交付真正的效率点。
