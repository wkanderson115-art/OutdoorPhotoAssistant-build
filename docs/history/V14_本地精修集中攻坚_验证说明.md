# V14 本地精修集中攻坚（阶段交付）

本次基于 V13 工程实际修改：

- 增加 `LocalTiledRenderer`：输出以 1024/2048 像素块渲染到单张 RGBA8 位图，避免额外的整张 GPU 输出分配。**仍需整张最终位图，不是完全的低内存流式编码**。
- 主精修 `process` 接入分块输出，保留原图、预设和三个引擎接口。
- 修复场景识别时 UIImage EXIF 方向未传入 Vision 的问题。
- 前景实例分割增加 iOS 17 可用性保护。

## 四大关键项真实状态

1. 自动祛痘：仍缺训练并验证的瑕疵检测模型；保留人工选点纹理克隆，不能声称全自动。
2. 专用语义分割：人物、通用前景可用 API 已接入，宠物毛发和天空/植被的精细语义模型仍缺。
3. 48MP：新增分块输出，但仍需实际 iPhone 内存峰值、速度、接缝及崩溃测试；不保证 48MP 性能达标。
4. 商业审核：已有基础像素审计，身份/纹理/伪影审核未完成，不能自动出具商业认证。

## 验证范围

本环境没有 macOS Xcode/iOS SDK，不能运行 `xcodebuild` 或真机测试。ZIP 完整性检查不等于编译通过。
建议在 Mac 上使用 `xcodebuild -list -project OutdoorPhotoAssistant.xcodeproj` 并选择真实 scheme 与模拟器 destination 编译。对 12/24/48MP 各至少 30 张进行内存峰值、处理耗时、颜色/方向/接缝人工验收。
