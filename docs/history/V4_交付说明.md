# V4 下一阶段交付与边界

## 本次真实新增
- 保留原 20 类 80 预设、Vision 推荐、本地 Core Image 调色和 Seedream 原有独立图库入口。
- 新增 `CommercialQualityGate`：图像尺寸、JPEG 解码、sRGB 色彩空间基础验证；所有内容级商业审核仍需人工确认。
- 新增 `SafeFusion`：同尺寸、同方向且提供有效蒙版时，在线性 sRGB 工作空间内合成；不允许无蒙版直接覆盖。**目前未接 Seedream 自动返回，也未做图像配准。**
- 本地精修每次输出新的 JPEG 版本，不再覆盖上一版本；原图保留。
- 精修页面增加本地版本历史分享入口。

## 尚未实现（不能宣传为已完成）
1. 专业痘痘/痘印、毛发、商品等 80 套独立算法；目前主要是基础调色。
2. Seedream 自动按需调用、提示词编排、自动取回、图像配准、局部蒙版生成及完整融合工作流。
3. 人脸身份一致性、复杂纹理、AI 幻觉等质量模型；商业审核不能自动通过。
4. 原图/AI/融合版统一版本浏览器与任意历史回滚、任务断点恢复、预算熔断。
5. Xcode 编译与真机验证；本执行环境不包含 Apple SDK。

## 验收步骤
- 在 macOS + Xcode 打开工程，构建到真机；确认 App 权限、照片导入和三入口导航。
- 对同一照片本地精修两次，应保留两个不同 JPEG 路径，原图哈希不变。
- 检查 JPEG 文件 ICC 是 sRGB，尺寸正确，GPS 不被继承。
- `SafeFusion` 在图像尺寸不符或蒙版无效时必须失败，不得写入正式融合版。
- Seedream 仍通过原有图库入口单独使用；不得将该功能描述为自动双引擎。
