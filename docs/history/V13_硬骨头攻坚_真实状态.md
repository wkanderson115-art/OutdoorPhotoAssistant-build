# V13 本地专业精修：实质进展与未完成事项

## 本次源码变更
- 新增 LocalRetouchPreflight：对 12/24/48MP 进行像素与中间缓冲开销估算，按设备物理内存选择 Vision 代理图尺寸，防止每张图都按固定 1600 边长识别。
- RetouchPipeline 接入 preflight 并依据设备档位选择人物与宠物分割的代理图边长。
- 新增 LocalPortraitReview：Vision 人脸区域检测，供人工检查流程使用；不冒充自动痘痘识别。
- 保留 V12 的人像手动采样修复、人物/前景蒙版、版本存储与技术审核。

## 仍然不能宣称完成
- 自动痘痘/痘印分类和自动修复：需要有许可、可复现测试的 Core ML 模型以及标注集；本版不包含该模型。
- 宠物毛发、天空、植被的像素级语义分割：Vision 前景蒙版不能代替专用类别模型。
- 48MP 端到端分块渲染与峰值内存控制：preflight 只做估算，不等于实测或 tiled renderer。
- 商业画质认证：需要真实样张、人工双盲评价及各机型性能测试。
- 本环境无 Apple SDK，未进行 Xcode 编译或真机运行。

## 最终 Mac 验收命令
```sh
xcodebuild -list -project OutdoorPhotoAssistant.xcodeproj
xcodebuild -project OutdoorPhotoAssistant.xcodeproj -scheme OutdoorPhotoAssistant -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

## 验收集建议
人像 100 张（多肤色、弱光、眼镜、胡须），宠物 100 张（长毛/短毛/逆光），风景 100 张（云、树枝、建筑边缘），12MP/24MP/48MP 各至少 30 张；比较原图、V12、V13 的边缘伪影、肤质、颜色和处理时间。
