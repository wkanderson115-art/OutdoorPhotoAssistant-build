# V5 开发交付与剩余边界

已在 V4 基础上接入真实 Seedream API 编辑、结果下载、独立 AI 版本保存、双引擎顺序执行、一次调用授权和防重复调用；保守差异蒙版融合仅接受少量变化，拒绝大幅度重绘；融合结果仍需人工审核。新增版本文件枚举、原图字节核验。

**没有完成且不能宣传已完成**：80 套专用算法（V3 仍主要共用曝光、对比度、饱和度处理）；痘痘/痘印专用 Core ML 模型；高质量自动配准；可信的人脸身份一致性、纹理/幻觉审核；跨 App 重启的任务恢复与完整版本图库；用户可控成本精确报价（目前只限单张一次调用）；真机 Xcode 编译和商业验收。

**安全策略**：不支持 AI 的纪实预设禁止自动调用；AI 结果独立保存；尺寸不符或变化超过保守阈值时拒绝融合；原图不覆盖；不自动重试；用户明确打开一次付费许可后才调用。融合候选不代表商业审核通过。

**Mac 验证**：打开 xcodeproj，编译并修复可能出现的 Swift/SDK 兼容问题；在真机配置有效 Seedream Key 和模型；先验证本地输出，再测试 AI 独立输出和双引擎拒绝回退；确认原图哈希不变、版本不覆盖、JPEG sRGB 和照片隐私；检查 API 实际账单。
