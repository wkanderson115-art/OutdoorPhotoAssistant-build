# V15 本地精修质量与方向一致性专项

## 本次实际源码改动
- `RetouchPipeline.swift`：输入图像从原始 CGImage 统一执行一次 EXIF 方向归一化，避免某些 UIImage 输入路径发生双重旋转；质量审核按显示方向比较像素尺寸，原图归一化后再做差异比较。
- `RetouchPixelAudit.swift`：新增“新产生的高光/暗部裁切占比”和“相对边缘梯度保留率”指标，辅助发现过度降噪、过锐化。两者均为启发式信号，不是商业成片认证。
- `LocalRetouchPreflight.swift`：增加高内存开销提示。

## 仍然缺少的硬条件
1. 自动祛痘/痘印检测：没有已训练、已验证的专用 Core ML 模型；不能宣称完成。
2. 宠物毛发、天空、植被精细语义分割：当前 Vision 前景/人物蒙版不能代替专用分割。
3. 48MP 峰值内存：分块渲染仍要分配最终完整位图；需 Instruments 真机压力测试。
4. 商业质量审核：新增的图像统计指标不能替代纹理、身份与伪影的专用模型和人工盲评。

## 真实样张验收集建议
每个场景至少 30 张，包含不同曝光、肤色、年龄、毛色、逆光与夜景；每张同时检查原图、精修图、100% 局部裁切、尺寸/ICC/EXIF，以及低内存设备处理时间与峰值 RSS。
