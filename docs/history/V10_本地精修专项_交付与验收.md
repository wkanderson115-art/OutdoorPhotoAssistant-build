# V10 本地专业精修专项：交付与验收

## 本轮已修改（基于 V9 源码）

- 修正人像局部保护：对 Vision 识别出的眼睛、眉毛、鼻子、嘴唇，使用渐变遮罩减弱局部降噪；避免将特征区域当作普通皮肤处理。该策略为保守的局部处理，不是专业皮肤分割或痘印识别。
- 降低非人像的无谓全分辨率解码：仅对人像类别构造用于面部关键点检测的源图像，其他场景直接走 Core Image 图像链。
- 修正本地质量初审的尺寸检查：使用实际 CGImage 像素宽高，不依赖 UIImage 的 point 尺寸。
- 保留 20 类 80 个预设、三个引擎入口、原图独立保存、历史版本及 JPEG 质量门禁。

## 已执行的检查

- Swift 语法解析：`swiftc -frontend -parse`（针对修改的两个 Swift 文件），通过。
- Xcode 工程源码注册检查：RetouchPipeline.swift 与 RetouchSpecialist.swift 均在 pbxproj Sources 列表。
- ZIP CRC 完整性：已执行。

## 尚不能宣称完成的事项

1. 当前环境没有 Apple iOS SDK/Xcode，**没有进行 iOS 编译、运行、签名或真机测试**。Linux Swift 语法解析不是 Apple Framework 类型检查。
2. 自动痘痘/痘印检测、肤质频率分离与修复、宠物毛发语义分割、天空/植被精细蒙版、Core ML 专用模型仍缺失。没有训练好的模型权重或真实样张基准，不应宣称已达到商业级。
3. 12/24/48MP 内存峰值、GPU 耗时、温升、电池耗电与老机型兼容性尚未量测。
4. Seedream 融合仍是保守版本，缺少可靠的非刚性图像配准及语义一致性审核。
5. 商业交付仍需要人工检查主体、颜色、纹理、授权与输出格式。

```bash
xcodebuild -list -project OutdoorPhotoAssistant.xcodeproj
xcodebuild -project OutdoorPhotoAssistant.xcodeproj -scheme OutdoorPhotoAssistant -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```
