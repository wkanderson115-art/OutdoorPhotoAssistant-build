## 三、第一轮不是 7/7 —— 抓到的三处真问题

### ① 参考实现缺「兜底合规」→ 亮场景/浅色毛发被判裁切超限
缅因猫那张：`clipping_full = 0.0156 > 0.0100`，FAIL。
原因：Python 参考实现（`pipeline.py`）**没有** Swift V22 加的肩/趾压缩兜底，
亮地面 + 浅色毛一推曝光就出新增裁切。
修法：把 `shoulder_toe_repair` 移植进 `retouch_scene`（与 Swift `RetouchCompliance` 同一条曲线：
`x≤0.08 → 0.014+0.066·(x/0.08)`；中段斜率 0.9976；`x≥0.92 → 0.918+0.064·((x-0.92)/0.08)`），
门禁报裁切就压一次再重算。→ 猫那张裁切 0.0000、SSIM 0.959，通过。

### ② 参考实现「无差别抬黑」→ 截图类 SSIM 掉到 0.914
`protect_highlight_clip` 最后一行 `np.maximum(out, 0.012)` 把**每个像素**抬到 3/255。
对纯黑区域（截图黑边、夜景暗部、黑背景）这是把真黑改成灰：SSIM 在平坦黑区每个窗 ≈0.41，
整图直接掉到 0.914。
这是 Python 侧独有的 bug（Swift 从来没有这句，Swift 靠 compliance pass 管两端）。
修法：删掉这句，两端交给肩/趾压缩。→ 同一张图 SSIM 从 0.914 → **0.999**。

### ③ 文档/截图类被当成「风格照」处理 → 结构必被改
即便跳过 WB/去雾/LUT/vignette，还有 `highlight_rolloff` 会压纯白 UI 区。
修法（两端口径一致）：
- Python：`retouch_scene(document_mode=True)` 跳过 WB / 去雾 / 曝光归一化 / 高光滚降 /
  LUT / clarity / vibrance / vignette，只留轻对比 + 轻锐化；门禁侧参考图也不再按 WB 增益对齐。
- Swift：`RetouchParameters.applyLook = false`（文档类），pipeline 跳过 `engine.grade` 与
  Lightroom 核心阶段；`preset(look:category:)` 里给「文档与翻拍」单独一档
  （clarity 0、sharpen 0.12、contrast 1.02、无暗角无颗粒）。

## 四、Swift app 侧同步改了什么

1. **四套品类口径**（`RetouchQualityGate.ShootingMode`）：

   | 口径 | 纹理区间 | SSIM | 肤色判定 |
   |---|---|---|---|
   | portrait 人像 | 0.50–1.15 | ≥0.85 | 全套（ΔE/明度/p95/皮肤裁切/接缝/瑕疵） |
   | scene 风景 | 0.60–1.20 | ≥0.85 | 只作参考 |
   | product 商品/建筑/汽车/静物 | 0.60–1.45 | ≥0.85 | 只作参考 |
   | document 文档/翻拍 | 0.60–1.50 | **≥0.92** | 只作参考 |

2. **口径自动判定**（`RetouchPipeline.shootingMode(for:hasFace:)`）：
   `文档与翻拍 → document`；`商品/建筑/汽车/静物 → product`；其余按「有没有检出人脸」分 portrait / scene。
   优先级是**类别 > 有没有脸**——商品图里偶尔也有人脸，但交付标准是产品细节。

3. **文档类不套风格**：`RetouchParameters.applyLook`，pipeline 里 `engine.grade` 与
   Lightroom 核心阶段都受它控制。

## 五、还能再准的地方（下一轮）

- **auto 那张的“产品口径”偏乐观**：车队照片不是商品图，纹理 1.233 在 product 区间里合法，
  但它更像「人文街拍」——如果按街拍口径（scene 0.60–1.20）它会**超限**。
  说明「汽车与机车」这个类目混了两种题材：商品图 vs 街拍纪实。建议拆成两个子类。
- **截图检测没有自动化**：这次是我人工判定「这是截图」。app 应该能自己识别
  （检测大面积纯黑边 + UI 文字边缘 + 极高低频占比），然后自动切到 document 口径。
- **美食/宠物用的是 scene 口径**，纹理上限 1.20；如果以后给美食加「质感增强」档，
  需要像 product 一样单独放开到 1.35。
