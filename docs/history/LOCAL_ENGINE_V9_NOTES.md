# V9 本地精修：边缘引导细节保护

## 本次源码修改
- `RetouchSpecialist.finish` 在降噪之后不再直接对整张图使用锐化结果；先从降噪图提取边缘强度蒙版，再以场景强度将锐化图与降噪图混合。
- 人像边缘增强强度较低，宠物毛发及细节场景较高，夜景最低，减少平滑区域的过锐化。
- 保留 V8 的人脸区域保护、原图存储、高光保护和三个独立引擎入口。

## 尚未完成、不可声称完成
- 自动祛痘印模型、皮肤纹理重建、毛发修复和 AI 语义分割。
- Xcode iOS SDK 编译、设备性能与图像质量实测。

## 编译和验收
1. macOS Xcode 中 Clean Build Debug/Release；运行单元测试。
2. 使用人像、宠物、风景、夜景每类至少30张真实样张盲测，对比 V8 与 V9，检查光晕、边缘锯齿、纹理和色差。
3. 12MP/24MP/48MP 真机运行，测内存峰值、耗时、温升及崩溃。
4. 检查导出 JPEG 的 ICC sRGB、EXIF 方向、版本回退与原图哈希。
