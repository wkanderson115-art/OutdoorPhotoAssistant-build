# 全场景自动精修 V3 — 集成与验收说明

## 本次实际新增
- 20 个摄影类别、80 个独立 ID 的预设配置，包含曝光、对比度、饱和度和 AI 使用权限标记。
- App 新增「精修」Tab：相册导入、Vision 初步场景分类、预设选择、三引擎选择。
- 可执行的本地 Core Image 基础调色；结果存为独立 JPEG，原始文件字节单独保存到 Application Support。
- 现有 Seedream 功能保留在图库内，精修页可跳转至图库调用；AI 不会被未经授权地自动调用。
- JPEG 质量参数 0.95，写入临时文件后校验能解码，再移动为本地版本。
- Xcode 项目文件已通过原项目 gen_pbxproj.py 重新生成，新增 Swift 文件已列入项目。

## 明确尚未实现（不可宣传为已完成）
- 80 个专用算法：目前是 80 套参数与 AI 权限配置，使用共用基础调色算法。
- 自动痘痘/痘印定位、毛发修复、精细语义蒙版、复杂光影与高质量去噪。
- Seedream 自动编排、对齐、局部蒙版融合及融合结果的独立生成。
- 完整的自动商业质量门禁：身份一致性、纹理伪影、ICC/sRGB profile 逐项验证、授权审核。
- 历史版本列表/任意版本回滚 UI：当前原图、本地 JPEG 分开落盘，但尚无完整版本浏览器。
- iPhone 真机和 Xcode 编译：当前环境不是 macOS，无法完成这些验证。

## 风险与建议
- 预设识别使用 VNClassifyImageRequest 的英文标签关键词规则，属于保守的初步推荐，误分类时手动选预设。
- CIImage 输出的颜色管理需要在商业导出前进一步做明确 sRGB ICC 嵌入和回读检查；本版 JPEG 不应被视为已通过 sRGB 商业认证。
- Seedream API Key 不应存储在源代码或直接打包到公开应用。商业版使用代理服务和额度控制。
- 正式双引擎应先分别持久化 A 原图、B 本地、C AI，再验证配准并生成 D 融合；不合格时回退 B，不能自动标记 D 已通过。

## 在 Mac 上验证
1. 解压，打开 OutdoorPhotoAssistant.xcodeproj。
2. 使用 Xcode 16+（具体以本机 SDK 与部署目标为准）选择 iPhone 模拟器编译。
3. 测试导入人像、街景、宠物，核对自动推荐、手动切换、三个入口以及本地导出。
4. 强制终止 App 后重新打开，检查 Application Support 下原图与版本文件。
5. 对不同设备进行内存、性能、颜色一致性、授权和 Seedream 错误恢复测试。

## 下一阶段明确验收
- 商业导出必须嵌入 sRGB ICC 并验证、清理位置元数据、处理 HEIC/RAW 方向与色彩。
- 加入 Core ML 皮肤与宠物专用检测模型；基于测试集衡量准确率与纹理保留。
- 实现融合前后几何对齐、局部遮罩、AI 伪影检测、成本上限、任务取消和版本回滚。
- 建立 300 张授权样本的分类型对照集，并由人工审核输出质量。
