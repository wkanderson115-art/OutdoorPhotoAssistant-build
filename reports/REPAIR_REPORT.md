## 修复内容

| 问题 | 修改 |
|---|---|
| 三个 ObservableObject 服务未显式导入 Combine | 补充 Combine 导入，避免依赖框架的间接导入 |
| 像素分析用 Int 变量 `stride` 遮蔽 Swift 标准函数，调用处无法编译 | 改为 `bytesPerRow` |
| 访问不存在的 `AVCapturePhotoOutput.supportedMaxPhotoDimensions` | 从设备 activeFormat 查询并设置输出 maxPhotoDimensions，再用于拍照请求 |
| 访问不存在的主体区域监测支持属性 | 使用实际存在的启用属性 |
| 错误的 `videoMirrored` Swift 属性名 | 使用 `isVideoMirrored`，显式关闭自动镜像调整 |
| 异步 UI 发布隐式捕获可变的实例场景属性 | 先捕获场景值，避免显式 self 编译要求和跨线程读取 |
| iOS 18 的审美类型在可用性检查外声明和访问 | 以 VNRequest 保存，所有新类型访问限制在 iOS 18 分支内 |
| 手动开启 HDR 时未关闭自动 HDR，存在异常风险 | 先关闭自动调节，再按设备档位配置 HDR |
| 照片融合、畸变修正未检查支持条件 | 按输出支持状态配置，输出层启用后才请求畸变修正 |
| 切换镜头后未重新配置深度、人像与照片尺寸 | 在会话配置内重新设置，并同步发布支持状态 |
| 虚拟相机的硬件 1 倍不等于用户主摄 1 倍 | 按 constituentDevices 和切换倍率映射主摄基准 |
| 安装新镜头时倍率固定为 1，导致界面与实际视角不符 | 安装时应用用户倍率；不支持超广角的设备限制最低倍率 |
| 切换摄像头失败会移除原有输入，导致黑屏 | 失败时恢复之前的输入与设备 |
| 快速重复拍摄可产生重叠请求 | 拍摄进行时拒绝新请求，后处理期间禁用手动快门 |
| 高清设置跨线程读写，原锁并未保护写入 | 主线程发布 UI 状态，会话队列保存并读取实际配置 |
| 停止后权限回调或中断恢复可能再次启动相机 | 会话队列维护运行意图，启动和恢复均检查该状态 |
| App 全局活跃事件会在非拍摄页面启动相机 | 生命周期移至拍摄页并检查当前选中标签，同步管理运动与定位 |
| 竖屏数据已物理旋转，Vision 又旋转一次 | 对竖屏帧使用 up/upMirrored，与镜像预览对应 |
| 主体框未考虑全屏预览 aspectFill 的裁切 | 按实际视频帧宽高比映射主体框，并与预览对齐安全区域 |
| 定位 stop 后 started 未重置，无法再次开始 | 停止时重置状态，授权回调尊重运行意图，保留已知太阳时 |
| 关闭自动拍摄未取消倒计时，倒计时每秒实际只有 0.65 秒 | 关闭时取消任务、清状态，拍摄前再次检查开关，间隔改为 1 秒 |
| 缩略图重复回调可能导致 DispatchGroup 多次 leave | 每个请求加锁去重，旧加载结果不覆盖新加载 |
| JPEG 编码失败时保存仍可能报告成功 | 编码失败立即返回明确错误，不执行空保存事务 |
| 保存后图库不刷新，权限变化也不刷新 | 成功保存后刷新已加载图库，每次进入图库重新检查权限并加载 |
| 美颜遮罩纵坐标与 Vision/Core Image 坐标系不一致 | 使用一致的底部原点坐标；仍需真机图像确认 |
| 点击原片后旧异步渲染覆盖原片；渲染中保存了旧结果 | 原片操作取消旧 token，当前渲染完成前禁用保存 |
| 校验脚本行数误数转义字符、依赖未固定、构建脚本直接清空 build | 修正行数、固定检查依赖、加入 macOS/SDK 前置检查、隔离 IPA 暂存目录 |
