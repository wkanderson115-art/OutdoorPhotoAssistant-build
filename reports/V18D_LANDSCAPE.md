# V18d 横屏支持

## 行为
* 只有**拍摄界面**可以旋转（竖屏、左横屏、右横屏；不含倒置）。设置、拍后预览、图库、精修台仍锁竖屏。
* 拍摄界面进入设置 / 预览时会先转回竖屏，返回后恢复可旋转（`OrientationPolicy`）。
* 横屏布局：左侧取景（4:3 等比缩放），右侧一列可滚动的控制区；竖屏布局不变。
* 手机系统开了「旋转锁定」时界面不会旋转，但照片和分析画面仍按手机真实朝向取景。

## 相机链路
* `CameraService` 用 `AVCaptureDevice.RotationCoordinator` 跟随手机朝向，同时设置照片输出、视频分析输出和预览层的旋转角度（替换了写死的 `.portrait`）。
* 分析帧是「摆正」的画面（竖屏 3:4、横屏 4:3），Vision / AI 导演继续用 `.up`，不需要额外换算坐标。
* 拍出的照片带正确的 EXIF 方向，后面的精修、保存代码本来就按 EXIF 处理。
* Core ML 模型把画面宽高比当输入，横竖屏共用同一个模型。

## 已知限制
* 「半身 / 完整人物」等取景预设的主体占比是按竖屏人像调的，横屏沿用同样的高度占比，需要实拍后再调。
* `MotionService` 没改（界面没有使用它的 roll / pitch；水平线提示来自 Vision）。
* 未在 Xcode 编译、未真机验证。
