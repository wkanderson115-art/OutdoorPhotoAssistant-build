## 从画面到动作

AVCapture视频帧 → Vision人脸/完整人体/显著主体与场景识别 → 联合人物框与32×32采样明暗色彩证据 → 摄影规则与候选构图评分 → 归一化尺寸Kalman平滑 → 连续4次确认、1.4秒冷却和原始框裁切否决 → CameraService执行设备范围内的自动变焦。

每次最多推近15%或拉远15%，逐步趋近目标。全范围表示设备当前模式允许范围，不是一次跳到最大倍率。手动操作后暂停自动变焦8秒。失去可靠主体、机身不稳、低光或低细节时阻止推近；多人靠边先拉远。切前后摄重置控制状态；前置设备允许变焦时也可参与自动取景。

## 五类摄影知识如何参与决策

| 知识 | 输入证据 | 本轮作用 |
| --- | --- | --- |
| 构图 | 主体中心、框边缘、占比、水平线 | 居中与三分可选择；评分候选视野；留白与边界保护 |
| 光线与色彩 | 亮部/暗部比例、主体与整体明暗差、左右画面亮度、饱和度和红蓝差 | 逆光提醒、适度曝光补偿、高光保护及限制过度提阴影；红蓝差不是色温计，左右亮度不是实际光源方向 |
| 滤镜 | 场景置信度、人物、高饱和及同类场景用户反馈 | 自然肤色优先、场景滤镜、强度上限及偏好适配 |
| 人物定位 | 人脸、完整人体、多人联合框 | 不再用单独人脸框代表全身；保护合影与头顶空间；只有人脸时不承诺全身入镜 |
| 摄影技巧 | 稳定性、细节估计、暗光、硬件倍率及手动操作 | 避免拉风箱，抑制劣质数字放大，等待稳定；不把变焦当成改变机位、透视或物理光圈 |

取景目标可选：自动、环境、完整人物、突出主体。构图偏好可选：自动、居中、三分。不能移动手机本身，也不能恢复传感器没有记录的细节。

## “学习”的真实含义

1. 视觉识别使用系统现有Vision模型，本轮没有训练或替换其权重。
2. 摄影知识被编成可执行的评分、约束、曝光与滤镜策略，不是给模型上传书籍后宣称已掌握。
3. 拍后复盘有“喜欢这个效果 / 主体太小 / 主体太大”。只有用户明确反馈才更新偏好，不把自动保存等同于喜欢。
4. 同场景、主体类型与单人/合影分别保存统计。至少3次相关反馈后采用；用有界指数更新调整占比、滤镜票数及强度。主体大小投诉不计为滤镜批准。
5. 显式指定取景目标时，不用自动占比学习覆盖该目标。手动滤镜仍服从用户选择。
6. 偏好保存在本机UserDefaults，可关闭使用、可清除；不存人脸身份、不上传照片、不自动下载文章训练。

这是具备有限在线偏好更新的本地摄影决策系统，不是已经训练完成的通用摄影大模型。

## 怎么开启

设置 → AI导演：打开“AI导演自动决策”，按需打开“根据我的反馈调整”。
设置 → 智能拍摄：打开“自动取景”和“自动变焦”。
相机保持稳定并让可靠主体进入画面，连续确认后导演自行调整倍率。
设置 → 导演知识、决策与学习记录：查看5类规则、最近证据、反馈次数并清除偏好。
拍后复盘：查看本次快门冻结的决策说明，并提交一次反馈。新反馈从后续拍摄开始影响同类场景。

拍摄界面没有新增导演卡、评分或功能开启标签。24节摄影课程保留，学院增加偏好反馈次数。

建议真机至少覆盖：单人全身/面部、3人合影、人物快进快退、突然离开、暗光、逆光、日落太阳亮点、手动捏合与滑杆、前后摄、深度开关、设置/复盘/后台切换。验收目标是无裁人、无持续来回变焦、无越界、无后台误拍；具体通过与否须以真机记录为准。
