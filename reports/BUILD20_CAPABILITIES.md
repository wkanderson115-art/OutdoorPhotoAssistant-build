# Build 20 整体接入与可行性

| 能力 | 接入方法 | 效果与边界 |
|---|---|---|
| 拍摄意图 | 设置增加半身、特写、合影、运动，映射主体目标占比 | 不同取景目标采用不同变焦目标；不是语义理解所有拍摄故事 |
| 主体跟踪 | 连续框IoU、有效时间、丢失重置 | 降低目标跳变误拍；不是身份识别，多人交叉仍可能换目标 |
| 候选构图 | 保留多倍率候选评分、裁切保护，增加机位方向提示 | 可改变中心取景倍率，不能自动平移相机，尚未完整实现多种二维裁切方案比较 |
| 机位引导 | 主体偏离中心时给出转镜头方向；保留逆光、水平与完整性建议 | 无自动姿态/骨骼模型，不声称已识别肢体姿势 |
| 控制闭环 | 系统对焦/曝光/变焦就绪状态及时间新鲜度限制快门 | 等控制稳定后才自动拍；没有实现自动对焦点跟随、手动ISO与曝光时间优化或失败自动换策 |
| 快门机会 | 连续主体确认+质量确认+硬件稳定+画面连续1.5秒 | 无倒计时；不含闭眼与表情识别；运动意图只允许手动快门 |
| 景深 | 单人半身/特写/突出主体+开启深度+照片真实遮罩时低强度处理 | 只有拍后遮罩虚化，不是实时景深，未做遮罩边缘质量自动评估；缺遮罩保留原景 |
| 验片 | 已有拍后Vision评分加重拍建议及未测项目说明 | 不能自动判别闭眼/失焦/运动模糊；不是完整自动验片 |
| 偏好学习 | 保留本地明确反馈、同类场景偏好与重置 | 不重训视觉模型；未新增逐条撤销功能 |
| 适配 | 保留硬件支持探测、热状态降帧和单帧处理 | 未经过真机性能测试；设置列出真实边界 |

尚需后续实现：闭眼与表情识别、姿态分析、实时分割及遮罩边缘质量评价、运动目标快门策略、自动对焦点映射、失败换策、完整多构图候选比较、偏好撤销。这些不是简单开关可以实现，当前未完成。

验证：静态断言与接口安全检查通过；没有swiftc、Xcode、SDK与iPhone，不能声明编译成功或运行完成。
